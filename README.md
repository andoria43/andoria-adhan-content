# Andoria Adhan – muezzin library

Content for the Andoria Adhan app: the list of adhans users can download inside the app.

- `sources.json` – the recordings, each with its author and free licence (edit this to add one).
- `adhans.json` – the list the app reads (generated).
- `audio/` – normalised MP3 files (generated).
- `CREDITS.md` – authors and licences (generated).

Only recordings with a clear free licence (public domain, CC0, CC BY, CC BY-SA) are added.
